# MJU Registration Responsive Website

โปรเจกต์ตัวอย่างสำหรับงาน Web Technology:
- React + Vite
- JavaScript
- External CSS
- Semantic HTML
- Flexbox + CSS Grid
- Mobile-first + Media Queries
- 3 หน้า: หน้าหลัก, ผลการลงทะเบียน, ตารางเรียน/สอบ
- ใช้ข้อมูลตัวอย่างและปกปิดข้อมูลส่วนบุคคล

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal

## หน้าเว็บ

- `/` หน้าหลัก
- `/enrollment` ผลการลงทะเบียน
- `/timetable` ตารางเรียน/สอบ

## ทดสอบ Responsive

- Mobile: 390 × 844
- Tablet: 768 × 1024
- Desktop: 1440 × 900

หมายเหตุ: ข้อมูลนักศึกษาในโปรเจกต์เป็นข้อมูลสมมติ ไม่ใช่ข้อมูลส่วนบุคคลจริง
